## 🚀 Fitur Aplikasi
1. **Tambah Menu Baru (Create - POST):** Menginputkan data nama menu, harga, kategori, dan deskripsi ke database.
2. **Lihat Daftar Menu (Read - GET):** Menampilkan semua daftar menu yang tersedia dalam format JSON.
